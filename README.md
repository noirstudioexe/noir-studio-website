
# noir studio — website

A responsive portfolio website built with HTML and CSS.

## About

Noir Studio is a personal web development project focused on minimal design, responsive layouts, and clean navigation.

## Tech Stack

- HTML5 — page structure and content
- CSS3 — styling, layouts, and responsive design
- Git — version control
- GitHub — source code hosting

## Features

- Responsive layouts for desktop and mobile
- Multi-page navigation
- Project showcase and case study pages
- Custom styling and interactive hover effects

## Project Structure

- `index.html` — homepage
- `work.html` — selected work
- `portfolio.html` — portfolio page
- `noir-project.html` — Noir Studio case study
- `style.css` — website styling

Work in progress. Built as part of my ongoing web development journey.
